Getting started

  1. Choose Upload Source File and select one or more Python, Java, or C# files.
  2. Or choose Paste Code, select the source language, then paste code into the editor.
  3. Select Start Scan. The analyzer reads code statically; it does not run your uploaded code.
  4. Review findings by severity, open a finding for details and recommendations, or export a JSON, CSV, HTML, or SARIF report.
